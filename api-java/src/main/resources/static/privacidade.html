Privacidade: o que guardamos e por quê

Texto curto, em português simples. O NexoDesk é um projeto acadêmico: este texto descreve o que o sistema faz hoje, não foi revisado por advogado e não substitui orientação jurídica.

Quais dados guardamos

  • Da sua conta: nome, e-mail, senha (guardada só como código irreversível, nunca o texto), unidade (bloco e apartamento) e telefone, que é opcional.
  • Dos seus chamados: título, descrição, categoria, local, a foto, se você enviar, o status e as mensagens trocadas. Na foto, a localização (GPS) e os demais dados escondidos da câmera são removidos antes de guardar.
  • De uso: a data de cada mudança de status e os avisos que você recebe.

Para que usamos

Só para o condomínio receber, priorizar, atender e acompanhar os chamados. Não usamos os dados para publicidade e não os entregamos a terceiros.

Quem vê o quê

  • Síndico: vê todos os chamados, os dados de quem os abriu e a lista de usuários (nome, e-mail, unidade e perfil, sem telefone).
  • Zelador: vê só os chamados que o síndico atribuiu a ele.
  • Outros moradores: não veem os seus chamados.
  • Chamado anônimo: se você marcar "não mostrar meu nome", o síndico e o zelador veem "Anônimo", inclusive nas mensagens. Atenção: o que você escrever no texto do chamado continua visível a eles.

Seus direitos

  • Corrigir: em Minha conta você altera nome, unidade e telefone.
  • Excluir: em Minha conta, o botão "Excluir minha conta" apaga seu nome, e-mail, telefone e unidade e encerra o acesso. Os chamados que você abriu ficam no histórico do condomínio, sem identificação (o texto que você escreveu neles permanece; evite colocar dados pessoais nele).
  • Saber o que existe: peça ao síndico, que é quem administra o condomínio e os dados dele.

Quanto tempo guardamos

Enquanto a conta existir. Depois da exclusão, só o histórico dos chamados, sem identificação. Esta versão acadêmica ainda não tem prazo automático para apagar chamados antigos.

Como protegemos

Senha com bcrypt, sessão com cookie protegido, bloqueio de tentativas de senha, páginas sem código de terceiros e proteção contra envio de formulário por site falso. Nenhum sistema é totalmente seguro: não coloque neste sistema senhas, números de documentos ou dados bancários.

E-mail

O envio de e-mail de aviso vem desligado por padrão. Se o síndico ligar, o e-mail leva só o número do chamado e o novo status, nunca a descrição.
