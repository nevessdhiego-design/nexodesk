Quem cobre cada tipo de serviço

É o que o painel usa para marcar Indicado ao escolher o responsável de um chamado. Marque as funções que costumam atender cada categoria. É só uma sugestão: quem atribui é você. Toda categoria precisa de pelo menos uma função.

Funções que cobrem cada categoria de chamado

Etapas do serviço (checklist)

Cada categoria tem um modelo de etapas, criado quando o chamado recebe um responsável. Escreva uma etapa por linha (até 12, com até 120 caracteres). Chamados que já têm checklist não mudam.

Voltar ao padrão

Restaura a matriz e todos os checklists para o padrão do sistema. Não altera chamados nem checklists já criados.
