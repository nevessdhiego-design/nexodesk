Usuários do condomínio

Quem se cadastra entra como morador. Aqui você promove alguém a funcionário (zelador, faxineiro, eletricista, encanador, porteiro, segurança...; vê e atualiza só os chamados atribuídos a ele) ou a síndico (acesso total), e desativa quem não deve mais entrar. Mudar o perfil ou desativar encerra as sessões abertas da pessoa. Você não altera a sua própria conta aqui, e o condomínio sempre mantém pelo menos um síndico ativo.
